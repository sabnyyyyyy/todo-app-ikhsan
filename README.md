# Todo App

Project praktikum PWEB: aplikasi Todo dengan frontend Next.js dan backend Express.js + MySQL.

| Folder         | Isi                                                                  |
| -------------- | -------------------------------------------------------------------- |
| `frontend/`    | Next.js (App Router) + TypeScript + Tailwind + cmlabs UI (Tugas #2–#3) |
| `backend/`     | RESTful API Express.js + TypeScript + MySQL + JWT (Tugas #4–#6)      |
| `screenshots/` | Screenshot hasil pengujian API                                       |

## Menjalankan

**Backend** (lihat [backend/README.md](backend/README.md) untuk setup database dan `.env`):

```bash
cd backend
npm install
npm run dev
```

**Frontend**:

```bash
cd frontend
npm install
npm run dev
```
